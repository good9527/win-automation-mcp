# 💻 win-automation-mcp

极速、高精度、完全离线的 Windows 桌面自动化 MCP 服务器。

## 功能特性

- 🖱️ 鼠标控制（移动、点击、拖拽）
- ⌨️ 键盘输入（文字输入、快捷键组合）
- 📸 屏幕截图（全屏、区域、窗口级别）
- 🪟 窗口管理（查找、激活、调整大小）
- 🔍 OCR 文字识别（基于 Windows 原生 API）

## 安装

```bash
pip install -e .
```

## 使用

作为 MCP 服务器启动：

```bash
python server.py
```
